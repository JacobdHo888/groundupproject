# GroundUp - Demo Video Script (3 Minutes)

**0:00–0:20 — Hook**
- *Screen*: Landing page
- *Narration*: "Gen Z is the most financially stressed generation alive. Student loans, high rent, entry-level salaries. Most financial apps weren't built for them. GroundUp was."

**0:20–0:40 — Personality Quiz / Onboarding**
- *Screen*: Quiz flow / Onboarding steps
- *Narration*: "It starts by understanding who you are financially — not just what you earn."

**0:40–1:10 — Onboarding + Dashboard**
- *Screen*: Step through onboarding, land on dashboard
- *Narration*: "In three steps, GroundUp builds your complete financial snapshot — health score, spending breakdown, debt countdown, and your personalized roadmap."

**1:10–1:40 — Agent Demo**
- *Screen*: Chat interface
- *Live demo*: type "Can I afford to move out in 6 months?" Show agent multi-step response with plan.
- *Narration*: "This isn't a chatbot. It remembers your full situation, reasons through it, and gives you a real answer."

**1:40–2:00 — MongoDB Integration Proof**
- *Screen*: MongoDB Atlas dashboard showing live documents (or the simulated MCP logs)
- *Narration*: "Every plan, goal, and transaction is stored and retrieved through MongoDB's MCP server — giving the agent persistent memory across every session."

**2:00–2:20 — Standout Features**
- *Screen*: Roadmap, Sharing Card, Celebration animation
- *Narration*: "From your Broke to Stable roadmap to shareable progress cards — GroundUp makes financial progress feel real."

**2:20–2:40 — Proactive Agent**
- *Screen*: Nudge notification appearing in chat (Weekly Recap)
- *Narration*: "And it doesn't wait for you to ask. GroundUp checks in proactively — because real financial health requires real accountability."

**2:40–3:00 — Closing**
- *Screen*: Landing page
- *Narration*: "Built for the Google Cloud Rapid Agent Hackathon. Powered by Gemini. Backed by MongoDB. Built for the generation that needs it most."
